# amplifier-bundle-revisioner
Helps validate risky assumptions and reformulate visions documents so they are successful

## Installation

```
npx skills add https://github.com/DavidKoleczek/amplifier-bundle-revisioner/tree/main/.amplifier/skills

mkdir -p ./.amplifier/skills
mv ./.agents/skills/* ./.amplifier/skills
```

## Usage

```
amplifier
```

"I have a vision document at ... help me find its risky assumptions and derisk it"
